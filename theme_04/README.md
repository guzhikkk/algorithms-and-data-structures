# Куча (пирамида)

## A. Хипуй!

- **Ограничение по времени:** 4 секунды
- **Ограничение по памяти:** 64 Мб

### Условие

Реализуйте структуру данных Heap для хранения целых чисел, поддерживающую следующие операции:

- **Insert(k)** — добавить в кучу целое число $k$ ($1 \le k \le 1000000$);
- **Extract** — извлечь из кучи наибольшее число и удалить его.

**Входные данные**
В первой строке задано общее количество команд $N$ ($1 \le N \le 100000$). Далее следуют $N$ строк с командами:
- `0 <число>` — операция `Insert`;
- `1` — операция `Extract`.

Гарантируется, что при вызове `Extract` в куче присутствует хотя бы один элемент.

**Выходные данные**
Для каждой операции извлечения выведите в отдельной строке полученное максимальное число.

### Пример

| Ввод | Вывод |
| --- | --- |
| 2<br>0 10000<br>1 | 10000 |

## C. Пирамида (минимум)

- **Ограничение по времени:** 2 секунды
- **Ограничение по памяти:** 64 Мб

### Условие

Реализуйте структуру данных «пирамида с поддержкой минимума», обрабатывающую следующие запросы:

- `CLEAR` — очистить пирамиду (удалить все элементы без вывода сообщений);
- `ADD n` — добавить в пирамиду целое число $n$ без вывода сообщений;
- `EXTRACT` — извлечь и вывести минимальное значение. Если пирамида пуста, вывести `CANNOT`.

**Входные данные**
Последовательность команд `CLEAR`, `ADD` и `EXTRACT`, записанных по одной в строке. Общее количество запросов не превышает $200000$.

**Выходные данные**
Для каждого вызова `EXTRACT` выведите ответ в отдельной строке.

### Пример

| Ввод | Вывод |
| --- | --- |
| ADD 192168812<br>ADD 125<br>ADD 321<br>EXTRACT<br>EXTRACT<br>CLEAR<br>ADD 7<br>ADD 555<br>EXTRACT<br>EXTRACT<br>EXTRACT | 125<br>321<br>7<br>555<br>CANNOT |

## E. Коммерческий калькулятор

- **Ограничение по времени:** 1 секунда
- **Ограничение по памяти:** 64 Мб

### Условие

Калькулятор за операцию сложения двух чисел берет комиссию в размере 5% от полученной суммы. Дана последовательность из $N$ чисел, которые нужно сложить. Поскольку порядок попарного сложения влияет на суммарную величину комиссии, определите минимальную общую стоимость выполнения всех операций.

**Входные данные**
В первой строке задано число $N$ ($2 \le N \le 10^5$). Во второй строке находятся $N$ натуральных чисел, каждое не больше 10000.

**Выходные данные**
Выведите минимальную сумму комиссии с округлением до двух знаков после точки.

### Примеры

| Ввод | Вывод |
| --- | --- |
| 4<br>10 11 12 13 | 4.60 |

<br>

| Ввод | Вывод |
| --- | --- |
| 2<br>1 1 | 0.10 |

## F. Таможня

- **Ограничение по времени:** 1 секунда
- **Ограничение по памяти:** 64 Мб

### Условие

В терминал поступает $N$ грузов. Для каждого груза известны время прибытия $T_i$ и длительность досмотра $L_i$. Досмотр должен начинаться без задержек сразу в момент прибытия груза, при этом один аппарат досматривает ровно один груз единовременно. Определите минимальное количество аппаратов, необходимое для обработки всех грузов без очередей.

**Входные данные**
Первая строка содержит целое число $N$ ($0 \le N \le 50000$). В последующих $N$ строках записаны пары положительных целых чисел $T_i$ и $L_i$ ($1 \le T_i \le 10^6$, $1 \le L_i \le 10^6$).

**Выходные данные**
Выведите наименьшее число аппаратов для непрерывного обслуживания потока грузов.

### Примеры

| Ввод | Вывод |
| --- | --- |
| 3<br>3 2<br>4 2<br>5 2 | 2 |

<br>

| Ввод | Вывод |
| --- | --- |
| 5<br>13 4<br>15 1<br>11 5<br>12 3<br>10 3 | 3 |

## G. Вычислительная ихтиология

- **Ограничение по времени:** 2 секунды
- **Ограничение по памяти:** 64 Мб

### Условие

В ряд расположены $n$ аквариумов с рыбками гуппи. Если текущий размер популяции в аквариуме равен $f$, следующая рыбка появляется через $\max(1000 - f, 1)$ секунд. Первая рыбка от начала эксперимента рождается также через $\max(1000 - a_i, 1)$ секунд.

Лаборант изначально стоит у 1-го аквариума в момент времени $t = 0$. Переход между соседними аквариумами занимает ровно 1 секунду. Чтобы зарегистрировать появление новой рыбки, лаборант обязан находиться около нужного аквариума ровно в секунду ее рождения. Требуется определить наименьший момент времени, когда родится первая рыбка, которую лаборант не сможет зафиксировать.

**Входные данные**
В первой строке задано количество аквариумов $n$ ($2 \le n \le 50$). В следующих $n$ строках даны начальные популяции колоний $a_i$ ($1 \le a_i \le 2007$).

**Выходные данные**
Выведите момент времени, в который произойдет рождение первой пропущенной рыбки.

### Пример

| Ввод | Вывод |
| --- | --- |
| 3<br>996<br>1<br>994 | 7 |
