# Тема 5. Двоичные деревья поиска

## A. Бинарное дерево (вставка, поиск, удаление)

- **Ограничение по времени:** 1 секунда
- **Ограничение по памяти:** 64 Мб

### Условие

Напишите программу, которая будет реализовывать действия в бинарном дереве поиска «вставить», «удалить» и «найти» (по значению). Программа должна обрабатывать запросы четырех видов:
ADD n — вставить элемент (если уже есть, вывести ALREADY, иначе DONE).
DELETE n — удалить элемент (если нет, вывести CANNOT, иначе DONE). При удалении узла с двумя потомками обязательно обменивать его значение с максимальным элементом левого поддерева.
SEARCH — вывести YES, если найдено, или NO, если нет.
PRINTTREE — вывести все дерево, используя алгоритм с точками в зависимости от уровня[cite: 1].

**Входные данные**
В каждой строке входных данных записан один из запросов ADD n, DELETE n, SEARCH n или PRINTTREE. Гарантируется, что общее количество запросов не превышает 1000, из них не более 20 запросов PRINTTREE[cite: 1].

**Выходные данные**
Для каждого запроса ADD, DELETE и SEARCH выведите соответствующее слово в отдельной строке. На запрос PRINTTREE надо выводить дерево согласно указанному в задаче алгоритму[cite: 1].

### Пример

| Ввод | Вывод |
| --- | --- |
| ADD 2<br>ADD 7<br>ADD 5<br>PRINTTREE<br>ADD 5<br>DELETE 3<br>ADD 0<br>PRINTTREE<br>DELETE 7<br>PRINTTREE | DONE<br>DONE<br>DONE<br>2<br>..5<br>.7<br>ALREADY<br>CANNOT<br>DONE<br>.0<br>2<br>..5<br>.7<br>DONE<br>.0<br>2<br>.5 |

## K. Следующий

- **Ограничение по времени:** 1 секунда
- **Ограничение по памяти:** 64 Мб

### Условие

Реализуйте структуру данных, которая поддерживает множество $S$ целых чисел, с которым разрешается производить следующие операции:
- `add(i)` — добавить в множество $S$ число $i$ (если он там уже есть, то множество не меняется);
- `next(i)` — вывести минимальный элемент множества, не меньший $i$. Если искомый элемент в структуре отсутствует, необходимо вывести -1[cite: 15].

**Входные данные**
Исходно множество $S$ пусто. Первая строка входного файла содержит $n$ — количество операций ($1 \le n \le 300\,000$). Следующие $n$ строк содержат операции. Каждая операция имеет вид либо `+ i`, либо `? i`. Операция `? i` задает запрос `next(i)`.
Если операция `+ i` идет во входном файле в начале или после другой операции `+`, то она задает операцию `add(i)`. Если же она идет после запроса `?`, и результат этого запроса был $y$, то выполняется операция `add((i + y) % 10^9)`[cite: 15].

**Выходные данные**
Для каждого запроса выведите одно число — ответ на запрос[cite: 15].

### Пример

| Ввод | Вывод |
| --- | --- |
| 6<br>+ 1<br>+ 3<br>+ 3<br>? 2<br>+ 1<br>? 4 | 3<br>4 |
